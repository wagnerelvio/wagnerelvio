# Projetos Acadêmicos e Tecnológicos

### Engenharia, Programação e Tecnologias Educacionais

Bem-vindo ao meu espaço no GitHub!

Este perfil reúne projetos acadêmicos, materiais didáticos, códigos de programação e experimentos voltados às áreas de engenharia, computação, matemática aplicada e sistemas embarcados.

## Áreas de interesse

- Programação em Python e Java
- Matemática Discreta e Lógica Matemática
- Sistemas embarcados com ESP32
- Internet das Coisas (IoT)
- Redes de computadores e comunicação de dados
- Simulação e análise de sistemas

## Projetos desenvolvidos

### 1. Teoria dos Conjuntos com Python

Exemplos práticos sobre união, interseção, diferença, diferença simétrica e produto cartesiano, incluindo gráficos no plano cartesiano.

### 2. Bancada Didática com ESP32

Experimentos de comunicação sem fio utilizando ESP32, com análise de RSSI, RTT, perdas de pacotes e transmissão de informações.

### 3. Modulação AM e FM

Simulações em Python para o estudo de sinais, frequências, portadoras e técnicas de modulação analógica.

## Tecnologias utilizadas

**Linguagens:** Python, Java, JavaScript e C/C++.

**Ferramentas:** Google Colab, Arduino IDE, GitHub, MATLAB, Node-RED e ThingSpeak.

## Objetivo

Compartilhar conhecimentos e desenvolver recursos educacionais que relacionem teoria e prática, incentivando a utilização de programação e ferramentas computacionais na aprendizagem de conceitos científicos e tecnológicos.
